# Калькулятор подарочных корзин «ВоВкусе»

Клиентский калькулятор для предварительного расчёта подарочных корзин. Сайт собирается в статические файлы и автоматически публикуется через GitHub Pages.

Средние закупочные цены, варианты состава, упаковка и правила расчёта находятся в `app/catalog.ts`.

## Обновление

После изменения файлов в ветке `main` GitHub Actions собирает и публикует новую версию автоматически.
